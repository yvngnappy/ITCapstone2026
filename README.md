## Quick Start
- We came up with our proposal, contract and pitch
- We chose our group name and topic which is an engine to analyze emails used for phishing 
- We brainstormed an idea that was ideal to students at Columbus State that receive fake emails used for phisihing attempts
- We decided on the coding language to use for this project which was Python which is the one language that everyone is most proficient
- We constructed the setup utilizing python sandbox and attempted visual studio due to incompatability with Python

```bash
git clone https://github.com/yvngnappy/ITCapstone2026/repo.git
cd repo
python phishing_classfier.py
```
